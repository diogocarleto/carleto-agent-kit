## UI Adaptation

Adaptation translates a UI across platform, framework, screen size, or register.

### Preserve

- User goal and task flow
- Information hierarchy
- Domain vocabulary
- State model and error recovery
- Accessibility intent

### Reinterpret

- Navigation patterns
- Input controls and gestures
- Density and spacing
- Typography scale
- System colors and platform components
- Motion and transition style

### Platform translation examples

- Web sidebar navigation may become native tabs, drawers, split views, or navigation stacks.
- Hover-only affordances need visible or touch-friendly alternatives.
- Dense desktop tables may become cards, grouped lists, master-detail views, or filtered summaries.
- Browser modals may become sheets, dialogs, navigation pushes, or full-screen flows.

Do not port pixels. Port purpose, hierarchy, and behavior.
